Set up Botmap on Mac or Linux

Botmap organizes Claude Code and Codex chats by project in a mind map. Install the desktop app, connect your existing agents and import the conversations you want to work with.

Write to eliaspfeffer@gmail.com. You get an answer from the person who builds it.

What do I need?

  • For Mac, Apple silicon (M1 or newer) and macOS 12 or later.
  • Claude Code or the Codex CLI installed and signed in on your computer. Your provider's subscription or API charges are separate from Botmap.
  • Node.js 18 or later only if you use the Mac terminal installer.
  • Your own OpenAI API key if you want optional dictation or GPT Live.

How do I install Botmap for Mac?

  1. Download the latest Botmap for Mac from the official release.
  2. Open the DMG and drag Botmap to Applications.
  3. Open Botmap from Applications. macOS may ask you to confirm the first launch. Do not disable macOS security checks.

You can also install with Node.js 18 or later:

npx --yes --allow-remote=all https://trybotmap.com/install-v1.0.2.tgz

The terminal installer checks the release checksum, developer signature, app identity and Apple notarization before installing. It leaves existing installations in place and opens the newest verified version it finds. Use Botmap's updater for an existing installation.

Use the complete command above. The unrelated botmap package on npm is not this app. You can read the installer documentation and source before running it.

Invite a friend outside your Tailscale network

Link the cards or topics you want to share to your friend on the map. Open their friend card and choose Copy external invite. They can open the link in a browser without a Tailscale account. Keep Botmap and Tailscale running while you work together.

The host needs Tailscale Funnel enabled. To host from Linux, your local user needs Tailscale operator permission. Choose Take access back on the friend’s card to revoke the link.

Install Botmap Tab Sharing

Share one Chrome tab with a friend from a connected browser window in Botmap 2.3.165 or later for Mac. Only the person sharing installs the extension.

Open Chrome Web Store

The Chrome Web Store listing is pending. You can install the preview ZIP manually.

Download preview ZIP

  1. Extract the ZIP to a folder you can keep.
  2. Open chrome://extensions in Chrome. Turn on Developer mode, select Load unpacked, and choose the extracted folder that contains manifest.json.
  3. In Botmap, choose Share tab on a connected browser window. Open Botmap Tab Sharing in Chrome’s Extensions menu and confirm the tab.

When the store listing opens, remove the preview from Chrome’s Extensions page before installing the store version.

How do I bring in my Claude Code and Codex chats?

Open Import on the map to bring in existing chats from your Mac. Keep Claude Code or Codex installed and signed in. Organize the imported chats under projects and topics, then open a node to read its conversation and send a reply.

How do voice replies work?

Add your own OpenAI API key in Botmap's Settings to use Mac dictation or GPT Live. These features send voice content to OpenAI and may incur API charges. You can use typed replies without adding that key.

Do I need a paid Botmap license?

Personal use and organizations of up to five people are free. Larger organizations need one USD 50 monthly subscription for the whole organization. Read the commercial license terms before subscribing.

Pair your iPhone

  1. On the Mac, open Botmap, then Settings, then “Your iPhone”, and turn it on.
  2. On the iPhone, open Botmap and tap “Scan the code”, or copy the link on the Mac and tap “Paste the link”.
  3. That’s it: the iPhone opens on Needs you from then on.

The iPhone can’t reach the Mac

Botmap has to be running on the Mac, and the iPhone has to reach the Mac’s address. With Tailscale, it needs to be on, on both, signed in to the same account. Then tap “Try again”.

Try it without a Mac

On the first screen, tap “Look around in a demo first”. The demo shows made-up agents; everything works, including dictation.

Pair with a different Mac

Tap the i at the top of the app, then “Pair with another Mac”, and scan the new Mac’s code. The old key is removed from the iPhone.
